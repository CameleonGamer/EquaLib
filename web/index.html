⚡ Deux méthodes pour installer EquaLib :

Option 1 (Direct en 1 clic) : Flash USB WebUSB

Branchez votre calculatrice en USB, cliquez sur « Flash USB Direct » puis sélectionnez votre NumWorks. L'application est téléversée et la calculatrice redémarre automatiquement !

Option 2 (Site officiel NumWorks) : Glisser-déposer .nwa

Cliquez sur « Télécharger mon application .nwa » puis glissez le fichier sur my.numworks.com/apps pour l'installer via l'outil officiel.

🕹️ Raccourcis dans EquaLib sur la calculatrice :

  • • Toolbox : Activer / Désactiver la LED du Mode Examen (1 Hz)
  • • Var : Basculer instantanément en Mode Panique Furtif
  • • Shift + Home / Toolbox + Back : Sortie secrète de la calculatrice furtive
  • • Back / Home : Quitter le sous-programme ou revenir au menu NumWorks
